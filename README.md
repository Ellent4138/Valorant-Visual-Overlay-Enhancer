## 📖 About this project

Valorant-Visual-Overlay-Enhancer helps you see important game information more clearly. It works as an external tool that sits on top of your game window. It processes data from the game to highlight key areas. This helps you understand what happens on the screen during a match. The utility uses a secure connection to draw information without changing your game files. This keeps your game performance stable and smooth.

The overlay works best when you follow these steps:

1. Launch the Valorant-Visual-Overlay-Enhancer application first.
2. Start the game through your normal launcher.

## ⚠️ Troubleshooting common issues

If you encounter problems, check these solutions:

- Overlay does not show: Check that your game uses Borderless Windowed mode. Fullscreen mode often blocks external overlays.
- Low frame rates: Close other high-demand applications before you start. Clear your temporary files to gain extra system space.
- Application crashes: Right-click the application icon and select Run as Administrator. This gives the program permission to draw over other windows.
- Anti-virus warnings: Some security programs might flag external tools. You may need to add an exception for this application in your security settings to allow it to run.
- Update failure: Visit the primary download link again to ensure you have the most current version. Old versions might lose compatibility after a game patch.
